# 对局流程设计（基于 AGameMode）

## 一、类的职责划分

卡牌对局是**服务器权威**的，客户端不执行规则逻辑。

| 类 | 存在范围 | 负责内容 |
| --- | --- | --- |
| `ACardGameMode` | 仅服务器 | 流程推进、合法性校验、发牌/抽牌结算、胜负判定 |
| `ACardGameState` | 服务器 + 客户端 | 当前阶段、当前行动座位、回合数、阶段截止时间、胜者 |
| `ACardPlayerState` | 每个玩家 | 手牌、牌库、法力水晶、英雄引用、疲劳、是否阵亡 |
| `ACardPlayerController` | 每端 | Server RPC，把客户端请求转发给 GameMode |

> 客户端没有 GameMode 实例，所有需要 UI 显示的状态都必须放在 GameState / PlayerState 上复制。

## 二、两层状态机

引擎层（`AGameMode::SetMatchState`）只表达"开没开局"：

```
WaitingToStart ──► InProgress ──► WaitingPostMatch
```

游戏层（自定义枚举 `ECardMatchPhase`，存于 GameState）表达回合流程：

```
Mulligan ──► TurnStart ──► MainPhase ──► TurnEnd ──┐
   │                            ▲                   │
   └──────────── GameOver ◄─────┴───────────────────┘
```

| 阶段 | 说明 | 退出条件 |
| --- | --- | --- |
| `Mulligan` | 起手换牌 | 全部玩家确认 / 超时 |
| `TurnStart` | 法力水晶 +1 并回满、抽牌、疲劳结算 | 演出延时结束 |
| `MainPhase` | 玩家可出牌、攻击、结束回合 | 玩家请求结束 / 回合超时 |
| `TurnEnd` | 回合结束触发、表现 | 演出延时结束 |
| `GameOver` | 结算胜负 | — |

## 三、GameMode 的重写点

**构造函数**

- 指定 `GameStateClass` / `PlayerStateClass` / `PlayerControllerClass`
- `bDelayedStart = true`，避免单人进入就开局

**生命周期钩子**

| 钩子 | 作用 |
| --- | --- |
| `PostLogin` | 分配座位号 `SeatIndex`，把 PlayerController 的 Pawn 记为 `Hero` |
| `Logout` | 中途退出按认输处理，标记阵亡 |
| `ReadyToStartMatch_Implementation` | 玩家数达标才返回 true |
| `HandleMatchHasStarted` | 重置数据，进入换牌阶段 |
| `HandleMatchHasEnded` | 对局收尾 |

**阶段推进函数**

```
EnterMulliganPhase   // 定先手、发牌、限时
EnterTurnStartPhase  // 回合开始结算
EnterMainPhase       // 开放操作，启动回合计时
EnterTurnEndPhase    // 结算并延时推进
AdvanceToNextTurn    // 按座位号轮转到下一个存活玩家
EnterGameOver        // 置胜者，调用 EndMatch()
```

**对外接口**（由 PlayerController 调用）

- `RequestEndTurn(PlayerState)`
- `RequestMulligan(PlayerState, 要换的牌ID列表)`
- `RequestPlayCard(PlayerState, InstanceID, 目标位置)`

三者开头做同样校验：**当前是否 MainPhase** + **是否当前行动玩家** + **费用是否足够**。

## 四、实现要点

1. **用 Timer，不用 Tick**。回合限时与演出延时交给 `FTimerManager`；阶段截止时间写入 GameState，客户端用 `截止时间 - GetServerWorldTimeSeconds()` 本地倒计时。
2. **必须有超时兜底**。换牌超时视为放弃，回合超时自动结束，避免掉线卡死。
3. **隐藏信息用 `COND_OwnerOnly`**。手牌与牌库只同步给拥有者，对手仅能读到单独复制的 `DeckCount`。
4. **牌库空 → 疲劳伤害递增；手牌超上限 → 爆牌**，统一在 `DrawCards` 中处理。
5. **卡牌效果不进 GameMode**。GameMode 只做扣费与移出手牌，效果通过蓝图事件或 GAS Ability 执行（对应 `FCardItem::Ability`）。
6. **阶段函数开头做状态判断**，防止 Timer 与玩家请求并发导致重入。
7. **英雄血量读取要防空**，AttributeSet 未挂载时不判定死亡。

## 六、可配置规则项

| 配置 | 说明 |
| --- | --- |
| `PlayersToStartMatch` | 开局所需人数（单人测试可设 1） |
| `FirstPlayerHandSize` / `SecondPlayerHandSize` | 起手牌数，当前策划案为 4 张 |
| `DeckSize` | 牌库张数 |
| `MaxManaCrystal` | 法力水晶上限 |
| `MaxHandSize` | 手牌上限，超出爆牌 |
| `MulliganTimeLimit` / `TurnTimeLimit` | 换牌与回合限时 |
| `TurnStartDelay` / `TurnEndDelay` | 阶段演出延时 |
