# 基本策划案

## 一、基本元素

### 1. 卡牌

| 项目 | 说明 |
| --- | --- |
| 使用成本 | 使用卡牌需要花费 |
| 卡牌属性 | 花费、等级、分类、卡牌能力 |
| 卡牌信息 | 名称、描述、图片 |

### 2. 手牌区（UI）

- 玩家手中最多持有 **10** 张牌。
- 每个回合开始时，玩家会收到一张牌。
- 默认开局时玩家手中有 **4** 张牌。
- 玩家将手牌拖出手牌区即可使用。

### 3. 废牌区（UI）

- 使用后的牌会放入废牌区。

### 4. 牌堆区（UI）

- 玩家配置的牌。

### 5. 随从区（场景）

- 玩家召唤的随从所在的区域。

### 6. 随从

- **随从属性**：MaxHP、HP、ATK
- **随从技能**：需支持配置多个技能
- 随从默认拥有攻击能力

### 7. 技能

| 类型 | 说明 |
| --- | --- |
| 主动技能 | 需要玩家主动触发 |
| 被动技能 | 需要触发某些条件后触发 |

## 二、玩法规则

1. **游戏准备**：玩家开始时有四张牌。
2. **回合开始**：玩家回合开始时会从牌堆顶抽一张牌。
3. **回合进行时**：玩家可以出牌，让随从攻击其他随从，或者攻击玩家。
4. **回合结束**：玩家回合结束时，玩家禁止出牌。
5. **胜利条件**：杀死对方玩家角色。
